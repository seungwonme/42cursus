## 다중 클라이언트 채팅 서버를 구현하시오. 서버는 다음 조건을 만족해야 합니다.

1. 기본 동작
   - 서버는 명령행 인자로 포트 번호를 하나 받아 해당 포트에서 클라이언트 접속을 기다린다.
   - 새로운 클라이언트가 접속하면, 서버는 해당 클라이언트에게 고유 ID를 할당한다. 이 때 할당되는 ID는 0부터 시작하여 새 클라이언트마다 1씩 증가한다.
   - 새 클라이언트가 접속하면 `server: client <ID> just arrived`라는 메시지를 다른 모든 클라이언트에게 브로드캐스트한다.
   - 클라이언트가 접속 종료(연결 해제)하면 `server: client <ID> just left`라는 메시지를 다른 모든 클라이언트에게 브로드캐스트한다.
2. 메시지 전송
   - 클라이언트는 서버에 문자열을 전송하며, 서버는 각 문자열이 개행 문자(\n)로 끝날 때마다 이를 하나의 메시지로 간주한다.
   - 메시지는 `client <ID>: <메시지>` 형식으로 다른 모든 클라이언트에게 브로드캐스트된다.
   - 메시지는 클라이언트 단위로 별도의 버퍼를 사용하여 누적 처리해야 한다. (즉, 클라이언트 한 명이 여러 줄에 걸쳐 메시지를 전송하더라도 '\n'이 등장할 때까지 하나의 메시지를 받는 것으로 처리한다.)
3. 입출력 처리 방식
   - `select()` 함수를 이용하여 여러 소켓(서버 소켓 + 클라이언트 소켓)을 비동기적으로 처리한다.
   - `FD_SET`, `FD_CLR`, `FD_ISSET` 등의 매크로를 이용해 파일 디스크립터 집합을 관리한다.
   - 모든 에러 상황(소켓 생성 실패, 바인딩 실패, 클라이언트 소켓 오류 등)에서 적절히 에러 메시지를 출력하고 프로그램을 종료한다.
4. 기타 조건
   - C 표준 라이브러리와 POSIX 소켓 관련 함수(`socket`, `bind`, `listen`, `accept`, `select`, `recv`, `send`, `close`, `FD\_\*`)만 사용 가능하다.
   - 프로그램 흐름, 변수명, 구조체 등의 구체적인 구현은 자유이나, 위 기능 요구 사항을 모두 만족해야 한다.

입력 예시:

```bash
./server 8080
```

(여기서 8080은 서버가 리스닝할 포트 번호를 의미한다.)

출력 예시 (동작 예시 시나리오):

- 클라이언트 A 접속 시:
  `server: client 0 just arrived`
- 클라이언트 B 접속 시:
  `server: client 1 just arrived`
- 클라이언트 A가 “Hello\n” 전송 시:
  `client 0: Hello`
- 클라이언트 B가 “How are you?\n” 전송 시:
  `client 1: How are you?`
- 클라이언트 A 종료 시:
  `server: client 0 just left`

## 테스트 방법

```bash
nc localhost 8080
telnet localhost 8080
```
